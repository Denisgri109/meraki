## 2024-05-15 - React Native Accessibility Patterns\n**Learning:** The project relies heavily on React Native's `TouchableOpacity` for interactive elements that contain only an icon (e.g., from `@expo/vector-icons`). These icon-only buttons often lack accessibility metadata, meaning screen reader users are left without context about what the button does.\n**Action:** When implementing or modifying icon-only `TouchableOpacity` components, always add `accessibilityRole="button"`, a descriptive `accessibilityLabel`, and ideally an `accessibilityHint`.
